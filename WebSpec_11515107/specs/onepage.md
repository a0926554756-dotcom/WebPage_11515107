### 1.1 品牌語氣與風格定位

- **視覺調性**：極致高奢、沉穩大地、莊園職人、簡約純粹、溫潤醇厚。
- **色彩策略**：以濃縮黑褐（`#19100a`）與沉厚深焙啡褐（`#251710`）為基底，搭配醇黑摩卡棕（`#3e2417`）與醇焙琥珀棕（`#683e26`）；輔以溫潤象牙米白（`#faf7f2`）維持閱讀舒適度；點綴典雅香檳金（`#cfa858`）與克麗瑪暖金光（`#e2a866`），營造頂級精品莊園的尊榮感。

## 2. 文件與技術邊界

- 使用標準 HTML5、原生 CSS3、原生 Vanilla JavaScript (ES6+)。
- 頁面僅包含 1 個 `<style>` 與 1 個 `<script>` 區塊，無需建置工具，本機直接開啟或靜態托管即跑。
- 外部字型資源為 Google Fonts：`Noto Sans TC`、`Noto Serif TC`、`Cinzel`、`Playfair Display`。
- 圖像系統不使用外部相片或未授權外部圖檔；Logo 徽章、Hero 主視覺咖啡豆、星級評鑑、購物車與清單圖示皆由 CSS 漸層與自包含 SVG 向量路徑構成。
- 頁面包含 7 大主要 `<section>`、4 個咖啡商品 `<article>`、1 個側邊品味車抽屜 `<aside>` 與全域 Toast 提示。
- 導覽錨點均為同頁平滑捲動，不使用外部連結跳轉。

## 6. 互動功能與前端狀態管理

### 6.1 前端資料狀態模型

```javascript
let cart = [];          // 結構：[{ name: string, price: number, quantity: number }]
let discountAmount = 0; // 折抵金額 (預設 0，套用成功折抵 100)
let appliedCoupon = '';  // 已套用之折扣碼 ('MRBROWN' 或 'BROWNCOFFEE')
```

### 6.2 購物車抽屜互動規格

1. **開啟與關閉**：
   - 點擊 `#openCartBtn` 開啟；點擊 `#closeCartBtn` 或背景遮罩 `#cartOverlay` 關閉。
   - 開啟時 `cartDrawer` 與 `cartOverlay` 添加 `.active` 類別，`document.body.style.overflow = 'hidden'` 鎖定背景捲動。
2. **加入品味車 (`addToCart`)**：
   - 讀取按鈕之 `data-name` 與 `data-price`。
   - 若商品已存在則 `quantity += 1`，否則新增資料項。
   - 呼叫 `renderCart()` 重繪介面並觸發 Toast：「已將『品名』加入品味車」。
3. **數量控制與自動移除**：
   - 點擊 `+` 按鈕增加數量。
   - 點擊 `-` 按鈕減少數量；若數量減至 0 則自動自陣列刪除該品項。
4. **折扣代碼驗證**：
   - 輸入 `MRBROWN` 或 `BROWNCOFFEE`：
     - 若購物車有商品，折抵 NT$ 100，顯示折扣列並扣抵小計。
     - 若購物車為空，提示「請先加入喜愛的咖啡豆再套用折扣碼」。
   - 輸入無效代碼時發出錯誤 Toast。
5. **結帳模擬**：
   - 點擊結帳若無商品發出警告 Toast。
   - 購物車有商品時彈出確認提示對話框，清空狀態、重置金額並收合抽屜。

### 6.3 風味篩選 Tab 機制

- 點擊各 `.tab-btn` 時，為點擊項添加 `.active`。
- 讀取 `data-filter`，當值為 `all` 或與 `.bean-card` 的 `data-category` 吻合時顯示卡片（`display: flex`），其餘卡片隱藏（`display: none`）。

### 6.4 複製優惠碼 (Clipboard API)

- 點擊 `#copyCouponBtn` 呼叫 `navigator.clipboard.writeText('MRBROWN')`。
- 複製成功發送 Toast 提示。

### 6.5 行動版導覽選單

- 螢幕寬度小於 768px 時，漢堡鈕可開關 `#navMenu` 之 `.open` 類別。
- 點擊任一導覽連結後自動收合選單。

## 8. 無障礙性 (Accessibility / A11y)

- **語意標籤**：正確應用 `<aside>` 宣告促銷公告與品味車抽屜；使用 `<header>`、`<main>`、`<section>`、`<footer>` 建構清楚地標。
- **ARIA 屬性**：
  - 購物車側邊抽屜配置 `aria-label="購物車內容"`。
  - Toast 通知配置 `role="status"` 與 `aria-live="polite"`。
  - 表單輸入框配置明確之 `aria-label`。
  - 向量 SVG 配置 `aria-hidden="true"`。
- **視覺對比度**：濃縮黑褐背景（`#19100a`）搭配白色文字（`#ffffff`）超過 14:1，香檳金（`#cfa858`）對比深底色超過 8:1，達 WCAG 2.1 AAA 級最高可讀性規範。
